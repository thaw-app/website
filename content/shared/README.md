# Shared pages

Pages that read the same under Thaw's docs and Floe's. `scripts/sync-docs.mjs`
copies this folder into each product's docs, so edit them here, not in
`content/docs`.

In a link, write `{{docs}}` for the docs of whichever product the copy lands
in: `{{docs}}/contribute/guidelines` becomes `/docs/floe/contribute/guidelines`
in Floe's copy.
