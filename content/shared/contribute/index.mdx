Bug reports, code, documentation and translations are all welcome. Thaw and Floe share one set of rules, and each kind of contribution has its own place.

## Where to start

<Cards>
  <Card title="Thaw" href="/docs/thaw/development">
    Build the menu bar manager from source and run its tests.
  </Card>
  <Card title="Floe" href="/docs/floe/development">
    Build the launcher and work on its extension runtime.
  </Card>
  <Card title="Translations" href="{{docs}}/contribute/translations">
    Translate Thaw on Crowdin. No pull request needed.
  </Card>
  <Card title="Docs" href="{{docs}}/contribute/docs">
    Fix or add a page on this site.
  </Card>
</Cards>

Read the [contribution guidelines]({{docs}}/contribute/guidelines) before you open a pull request. They cover branch targets, commit titles, sign-off and tests.

## Reporting bugs

Search the existing issues first, then open one in the repository the bug belongs to:

- [Thaw issues](https://github.com/thaw-app/Thaw/issues)
- [Floe issues](https://github.com/thaw-app/Floe/issues)

Check [Frequent issues](/docs/thaw/frequent-issues) before filing for Thaw. Your problem may already have a workaround.

<Callout type="warn" title="Security problems">
  Do not report a vulnerability in a public issue or on Discord. Follow the [security policy]({{docs}}/security).
</Callout>

## Suggesting features

Open a feature request in the same repository. The [roadmap](/docs/thaw/roadmap) lists what is already planned, and [Ways to contribute](https://github.com/thaw-app/Thaw/issues/316) lists small tasks that need someone.

## Asking questions

Questions are welcome on the [community Discord](https://discord.gg/KDfWjWDnR4). Bug reports and decisions stay on GitHub, where others can find them.
