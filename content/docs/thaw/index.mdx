Thaw is a menu bar manager for macOS. It hides and shows menu bar items, adds search and hotkeys, keeps layout profiles, and restyles the menu bar.

New to Thaw? Start with [Getting started](/docs/thaw/getting-started): install it, grant its permissions and hide your first item.
